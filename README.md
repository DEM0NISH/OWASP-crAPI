# OWASP crAPI Local API Security Assessment

This repository contains the report for a time-boxed assessment of OWASP crAPI running in a local Kali/Docker lab.

- [VAPT report with sanitized screenshot exhibits](report.pdf)
- [Editable report source](report.md)

One cross-account vehicle-location BOLA issue was manually verified (CVSS 3.1: 4.3 Medium). The work was limited to the local lab; other planned vulnerability classes remain untested. See the report for scope and limitations.
